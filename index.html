ASAS

Apa itu Java?

Java ialah programming language untuk memberikan arahan kepada komputer. Prinsip terkenalnya ialah “Write Once, Run Anywhere”: kod yang sudah di-compile boleh berjalan pada pelbagai sistem yang mempunyai JVM.

⌘

Platform independent

Fail .class berjalan melalui JVM, bukan terus bergantung pada Windows atau macOS.

◇

Object-Oriented

Kod disusun menggunakan Class dan Object, seperti pelan rumah dan rumah sebenar.

♢

Matang & stabil

Ekosistem besar, dokumentasi luas dan digunakan selama puluhan tahun.

⌁

Banyak kegunaan

Digunakan untuk enterprise system, web backend, Android legacy, perbankan, cloud dan tools.

✦
Ingat

Java bukan JavaScript. Nama hampir sama, tetapi bahasa, cara berjalan dan kegunaannya berbeza.

Cara paling mudah ingat

Gunakan JDK.

Mahu menjalankan aplikasi?
Perlu Java runtime, yang mengandungi JVM.

Siapa jalankan fail .class?
JVM.

✓
Pembetulan istilah

Ejaan tepat ialah javac (huruf kecil), bukan “java c”. Arahan java pula digunakan untuk menjalankan program.

✦
Nota untuk kursus Java 8

Hubungan klasik yang kita belajar ialah JDK mengandungi JRE, dan JRE mengandungi JVM. Dalam pengedaran Java moden, JRE berasingan tidak semestinya disediakan; runtime boleh datang bersama JDK atau dibina khas untuk aplikasi. Konsep JRE sebagai persekitaran menjalankan Java masih betul.

03

KAMUS MINI

Istilah penting

Klik setiap istilah untuk melihat maksud, kegunaan dan perkara yang perlu diingat.

17 istilah
JavaProgramming language+

Bahasa untuk menulis arahan komputer. Contoh: System.out.println("Hello");. Ingat: fail source menggunakan sambungan .java.

JDKJava Development Kit+

Maksud: kit pembangunan Java. Fungsi: menyediakan semua yang kita perlukan untuk menulis, compile dan menjalankan Java, termasuk javac dan runtime. Contoh: projek kita menggunakan JDK 8. Ingat: jika mahu membina code Java, pasang JDK.

JREJava Runtime Environment+

Maksud: persekitaran untuk menjalankan aplikasi Java. Fungsi: menyediakan JVM dan Java class libraries yang diperlukan ketika program berjalan. Analogi: JRE ialah ruang dapur lengkap; JVM ialah tukang masak di dalamnya. Ingat: JRE fokus pada run, bukan membina code.

JVMJava Virtual Machine+

Maksud: mesin maya Java. Fungsi: membaca dan menjalankan bytecode dalam fail .class. Analogi: bytecode ialah resipi yang sama; setiap sistem operasi mempunyai JVM yang tahu cara memasaknya. Ingat: JVM tidak menulis atau compile source code.

javacJava compiler command · bukan acronym+

Maksud: nama command untuk Java compiler. Fungsi: menukar source code .java kepada bytecode .class. Contoh: javac Hello.java. Ingat: javac compile; command java menjalankan program.

javaxJava extension namespace · bukan acronym biasa+

Maksud: awalan Package yang digunakan oleh banyak API Java tambahan dan Java EE terdahulu. Contoh: javax.servlet.http. Ingat: Tomcat 9 menggunakan javax.servlet; jangan tukar kepada jakarta.servlet dalam projek kelas ini.

Jakarta EEJakarta Enterprise Edition+

Maksud: platform enterprise Java yang meneruskan teknologi Java EE di bawah Eclipse Foundation. Contoh: Tomcat 10+ menggunakan Package jakarta.servlet. Ingat: javax.servlet dan jakarta.servlet bukan Import yang sama.

ServletJava server component · bukan acronym+

Maksud: Class Java yang berjalan dalam Servlet Container. Fungsi: menerima HTTP Request dan menghasilkan HTTP Response. Contoh: HelloServlet. Ingat: Servlet berjalan di Tomcat/server, bukan dalam browser.

APIApplication Programming Interface+

Maksud: antara muka untuk software menggunakan fungsi software lain. Fungsi: memberikan peraturan, Class atau Method yang boleh digunakan tanpa membina semuanya dari awal. Contoh: Servlet API menyediakan HttpServlet. Ingat: API bukan semestinya website atau URL.

HTTPHypertext Transfer Protocol+

Maksud: protokol pemindahan hypertext. Fungsi: menetapkan cara browser dan server berkomunikasi. Contoh: browser menghantar GET Request dan Tomcat memulangkan Response. Ingat: HTTPS ialah HTTP yang dilindungi encryption.

RequestPermintaan daripada client+

Maksud: mesej yang dihantar oleh client seperti browser kepada server. Ia boleh membawa URL (Uniform Resource Locator), HTTP Method, header dan input pengguna. Contoh: GET /MyApp/devop/hello.

ResponseJawapan daripada server+

Maksud: mesej balasan server kepada client. Ia mengandungi status code, header dan body. Contoh: Servlet menghantar HTML (HyperText Markup Language) yang mengandungi <h3>Hello</h3>.

PackageSusunan dan namespace Class+

Mengelompokkan Class dan mengelakkan nama bertembung. Contoh projek: com.app1.devop.

ImportGunakan Class dari Package lain+

Membolehkan nama Class digunakan tanpa menulis nama Package penuh. Contoh: import java.io.IOException;.

Build Path & ClasspathLokasi rujukan compiler/JVM+

Build Path ialah tetapan Eclipse untuk source dan library ketika build. Classpath ialah senarai lokasi Class/JAR yang dicari ketika compile atau run.

JARJava Archive+

Maksud: fail arkib Java. Fungsi: mengumpulkan compiled Class dan resource dalam satu fail. Contoh: jstl-1.2.jar. Analogi: satu kotak alat yang mengandungi code siap guna.

WARWeb Application Archive+

Maksud: fail arkib aplikasi web. Fungsi: membungkus Servlet, halaman web, library dan konfigurasi untuk dihantar ke server. Deployment ialah proses meletakkan aplikasi/WAR pada Tomcat supaya boleh dijalankan dan diakses.

Tiada istilah dijumpai. Cuba kata kunci lain.

package com.app1.devop;

import java.io.IOException;
import java.io.PrintWriter;

import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

@WebServlet("/devop/hello")
public class HelloServlet extends HttpServlet {

    @Override
    protected void doGet(
            HttpServletRequest req,
            HttpServletResponse resp
    ) throws ServletException, IOException {

        // TODO Auto-generated method stub
        // super.doGet(req, resp);

        System.out.println("Selamat Petang Semua!");
        resp.setContentType("text/html");

        PrintWriter out = resp.getWriter();
        out.println("<h3>Hello from Java Servlet</h3>");
    }

    @Override
    protected void doPost(
            HttpServletRequest req,
            HttpServletResponse resp
    ) throws ServletException, IOException {

        // TODO Auto-generated method stub
        // super.doPost(req, resp);

        doGet(req, resp);
    }
}

GET vs POST

PerkaraGETPOST

BookmarkBoleh di-bookmarkTidak seperti GET

METHOD UTAMA

doGet() & doPost()

HelloServlet.java
protected void doGet(
    HttpServletRequest request,
    HttpServletResponse response
) throws ServletException, IOException {
    response.setContentType("text/html;charset=UTF-8");
    response.getWriter().println("<h3>Hello</h3>");
}

protected void doPost(
    HttpServletRequest request,
    HttpServletResponse response
) throws ServletException, IOException {
    doGet(request, response);
}
MASUK

HttpServletRequest request

“Sampul surat masuk” daripada browser. Digunakan untuk membaca parameter, header, session dan maklumat Request.

request.getParameter("name")
KELUAR

HttpServletResponse response

“Sampul surat balasan” kepada browser. Digunakan untuk menetapkan content type, status dan menulis output.

response.getWriter()
✓
Nama parameter fleksibel

req/resp dan request/response sama-sama sah. Nama panjang lebih mudah dibaca oleh beginner.

      Class Java di server yang menerima Request dan menghasilkan Response.

      Tomcat 9: javax.servlet.*
      Tomcat 10+: jakarta.servlet.*

      HTTP

      GET: baca data; parameter lazimnya pada URL.
      POST: hantar/cipta data; data lazimnya dalam body.

      Struktur MyApp

      src/main/java: source Java
      src/main/webapp: web root
      WEB-INF: dilindungi
      WEB-INF/lib: JAR

      Naming

      Class: PascalCase
      Method/Variable: camelCase
      Constant: UPPER_CASE
      Package: lowercase

      OOP

      Class: pelan · Object: instance · Method: tingkah laku · Constructor: setup Object · Inheritance: pewarisan
